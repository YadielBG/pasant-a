Proyecto Destacado: Sistema de Gestión de Tiquetes (JARS)

Desarrollo integral de un sistema de gestión de tiquetes con carga y consulta de archivos adjuntos, utilizando Python/Flask, JavaScript, HTML/Bootstrap y Microsoft SQL Server.

Impactos Principales

1. Trazabilidad de Solicitudes

Implementación de asignación automática de ID único por tiquete al registrarlo, evitando errores y facilitando seguimiento.

2. Gestión Documental

Módulo para adjuntar archivos (<5MB, validación de formato), organizándolos en el historial del sistema.

3. Estabilidad y Optimización

Corrección de duplicados deshabilitando el botón de envío durante el procesamiento y mantenimiento preventivo a SQL Server.
